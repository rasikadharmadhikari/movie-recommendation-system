
# MINI PROJECT REPORT — SHORT CONTENT

## Abstract
The Movie Recommendation System is a machine learning based application that recommends movies similar to a movie selected by the user. The system uses the MovieLens dataset and applies Content-Based Filtering. Movie genre information is converted into numerical vectors using TF-IDF, and Cosine Similarity is used to calculate similarity between movies. The highest-scoring movies are displayed as recommendations. A Streamlit GUI is provided for easy interaction.

## Problem Statement
Users may find it difficult to select a suitable movie from a large movie collection. A recommendation system can reduce this difficulty by automatically suggesting movies similar to the user's selected movie.

## Objectives
1. To build a simple movie recommendation system.
2. To use movie genre information for recommendations.
3. To apply TF-IDF and Cosine Similarity.
4. To develop a user-friendly GUI.
5. To visualize recommendation and dataset information.

## Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Streamlit
- MovieLens dataset

## Methodology
1. Download and load MovieLens data.
2. Select movie title and genre information.
3. Clean the genre text.
4. Convert genres into TF-IDF vectors.
5. Calculate Cosine Similarity.
6. Rank movies according to similarity.
7. Display top recommendations in the GUI.

## Conclusion
The developed system successfully recommends movies similar to a selected movie. The project demonstrates the practical use of content-based recommendation, TF-IDF, cosine similarity, Python data processing, GUI development and visualization.
